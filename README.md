## 📖 O que é JavaScript

JavaScript (JS) foi criado em 1995 por Brendan Eich, inicialmente para o **Netscape Navigator**. Hoje é padrão da web, rodando em todos os navegadores modernos.

✅ **Características**:
- Interpretada pelo navegador ou por engines como **Node.js**
- Tipagem dinâmica
- Multiparadigma
- Alta integração com HTML e CSS
